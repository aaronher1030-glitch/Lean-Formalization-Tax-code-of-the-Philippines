# Git bundles — full commit history of the nested repositories

These `.bundle` files are complete, self-contained git repositories (every commit,
branch and tag). They are here because the three sub-projects each had their own
`.git` directory, which a single repository cannot contain. The *files* of those
projects are committed as normal files elsewhere in this repo; these bundles add
back their **history**.

| Bundle | Original remote |
|---|---|
| `bettergovtarlacph-publish.bundle` | https://github.com/aaronher1030-glitch/bettergovtarlacph.git |
| `discord-mcp-lite.bundle` | https://github.com/aaronher1030-glitch/Aaron-s-Discord-MCP-server.git |
| `ph-tax-code-lean.bundle` | (none — local only) |

## Restore a project with its full history

```bash
git clone _git-bundles/ph-tax-code-lean.bundle ph-tax-code-lean
cd ph-tax-code-lean
git remote set-url origin https://github.com/aaronher1030-glitch/<your-repo>.git
git push -u origin --all
git push origin --tags
```

Verify a bundle at any time:

```bash
git bundle verify _git-bundles/ph-tax-code-lean.bundle
```

## What is *not* in this repository, and how to rebuild it

These were excluded because they are regenerable and far exceed GitHub's limits.

### 1. The Lean 4 toolchain (`tools/lean/`, 3.2 GB)

This is a stock, unmodified upstream build of **Lean 4.35.0 for Windows**
(`tools/lean/dist/lean-4.35.0-windows/`), pinned by:

```
ph-tax-code-lean/lean-toolchain → leanprover/lean4:v4.35.0
```

Rebuild it in one command with [elan](https://github.com/leanprover/elan):

```bash
curl -sSf https://raw.githubusercontent.com/leanprover/elan/master/elan-init.sh | sh -s -- -y
elan toolchain install leanprover/lean4:v4.35.0
```

Then point the project at it, e.g.:

```powershell
$env:LEAN_PATH = "tools\lean\dist\lean-4.35.0-windows\bin"
```

The upstream release is permanently hosted at
https://github.com/leanprover/lean4/releases/tag/v4.35.0

### 2. Node dependencies (`bettergovtarlacph-publish/node_modules/`, 109 MB)

```bash
cd bettergovtarlacph-publish
npm ci        # uses the committed package-lock.json — exact versions restored
```

### 3. Lean build outputs (`*.olean`, `*.ilean`)

Regenerated by:

```bash
cd ph-tax-code-lean && bash lean/run_demo.sh
```

## Optional: archived copies of the large directories

If a release was published on this repository, it carries compressed archives of
the above so you do not depend on upstream availability. See the **Releases** tab:

https://github.com/aaronher1030-glitch/Lean-Formalization-Tax-code-of-the-Philippines/releases

Restore the toolchain from such an archive with:

```powershell
Expand-Archive tools-lean-4.35.0-windows.zip -DestinationPath tools\lean\dist
```
