## Deviations

1. **Header wording (required, not cosmetic).** The brief's `HEADER_TEMPLATE` third line was
   `Every proof is closed by rfl or decide; no sorry, no native_decide.`, which contains the
   literal substrings `sorry` and `native_decide`. `test_forbidden_tokens` only strips
   `-- axiom audit`, so the verbatim header fails that test (and would also violate the
   "generated file must never contain `sorry` or `native_decide`" rule). The line was rewritten
   to `Every proof is closed by rfl or decide; no admitted goals, no kernel bypasses.`
   All other header lines, spacing, and the body of `render` are exactly as specified.
2. Nothing else deviated: no added validation, no extra helpers, no I/O in the renderer
   (`render` is pure text; file writing is left to Task 5's driver).
